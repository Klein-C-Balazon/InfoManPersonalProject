# **App Name**: StudyHub Tracker

## Core Features:

- User Registration & Authentication: Allow users to securely sign up and log in, and display their essential profile information such as display name, email, role, and associated college.
- College Roster Management: Manage a definitive list of colleges from which users can select, ensuring consistency for profile setup and visit logging.
- Visit Logging: Provide a simple interface for authenticated users to create and submit new library visit logs, including purpose of visit and their college affiliation.
- Personal Visit History: Enable individual users to view and review a comprehensive list of all their own past library visits.
- Comprehensive Visit Analytics (Admin): Offer an administrative dashboard for authorized personnel to view, filter, and analyze all recorded library visit logs across every user and college.
- User Account Moderation (Admin): Allow administrators to oversee user accounts, modify roles ('admin' or 'user'), and manage user access by blocking or unblocking accounts.

## Style Guidelines:

- Primary Color: A deep, calming academic blue, evoking focus and professionalism (#335699).
- Background Color: A subtle, light desaturated blue-grey, promoting an open and serene study environment (#F0F2F4).
- Accent Color: A clear and refreshing blue-cyan, used for calls to action and important highlights, creating visual interest (#52CAE0).
- Body and Headline Font: 'Inter' (sans-serif) for its modern, clear, and highly legible characteristics, ideal for data presentation and general readability.
- Employ a set of clean, functional, and easily recognizable icons to clearly denote actions and data types throughout the application.
- Adopt an organized and spacious layout, emphasizing clarity for forms, data tables, and user profile management sections to ensure ease of use.
- Incorporate subtle and smooth transitions for page navigation, form submissions, and data loading states, providing a polished user experience without distractions.
